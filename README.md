## ⚖️ Tathya · SIH 2026
<img src="https://capsule-render.vercel.app/api?type=rect&color=gradient&customColorList=6,11,18&height=70&text=Secure%20Case%20%26%20Evidence%20Management&fontSize=26&fontColor=ffffff" width="100%"/>

> Tamper-evident platform for legal case and evidence management, with SHA-256 integrity verification, blockchain hash anchoring, audit trails and a permission-aware RAG assistant. Smart India Hackathon 2026 prototype · PS **SIH26190** · NCRB / MHA track.

**Evidence verification flow**

```mermaid
sequenceDiagram
    participant O as Officer
    participant B as FastAPI
    participant M as MinIO
    participant L as Ethereum Ledger
    O->>B: Upload evidence
    B->>M: Store object
    B->>B: Compute SHA-256
    B->>L: Anchor hash on-chain
    Note over B,L: Later verification
    O->>B: Request integrity check
    B->>M: Re-hash stored file
    B->>L: Fetch anchored hash
    B-->>O: VERIFIED or INTEGRITY FAILURE
```

| Highlight | Detail |
|---|---|
| 🔐 Access control | JWT + bcrypt, 5 roles, case-level RBAC enforced on the backend; unauthorized access returns 404 so document existence never leaks |
| ⛓️ Integrity | SHA-256 per document version, hashes anchored on a local Ethereum node (the document itself is never on-chain) |
| 🧠 RAG | OCR, full-text search and permission-aware retrieval with source citations |
| 🧾 Traceability | Immutable document versions and an append-only audit trail |

## 🛡️ ShieldScan AI
<img src="https://capsule-render.vercel.app/api?type=rect&color=gradient&customColorList=1,5,14&height=70&text=Fake%20Message%20Detection%20%C2%B7%20~90%25%20Accuracy&fontSize=26&fontColor=ffffff" width="100%"/>

> AI-based web platform that classifies messages as **Real**, **Suspicious** or **Fake**, reads text from images with OCR, and scans emails automatically through Gmail API / IMAP.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white)
![TF-IDF](https://img.shields.io/badge/NLP_TF--IDF-8b5cf6?style=flat-square)
![Logistic Regression](https://img.shields.io/badge/Logistic_Regression-f59e0b?style=flat-square)
![Tesseract](https://img.shields.io/badge/Tesseract_OCR-5b21b6?style=flat-square)
![Gmail API](https://img.shields.io/badge/Gmail_API_/_IMAP-ea4335?style=flat-square&logo=gmail&logoColor=white)

```mermaid
flowchart LR
    A["💬 Text input"] --> D["🧹 Text cleaning"]
    B["🖼️ Image upload"] --> C["👁️ Tesseract OCR"]
    C --> D
    E["📧 Gmail API / IMAP"] --> D
    D --> F["🔤 TF-IDF features"]
    F --> G["📈 Logistic Regression"]
    G --> H{"Fake probability"}
    H -->|"under 40%"| I["✅ Real"]
    H -->|"40 to 60%"| J["⚠️ Suspicious"]
    H -->|"over 60%"| K["🚫 Fake"]
    G --> L["🔍 Human-readable explanation"]
    style I fill:#22c55e,color:#fff
    style J fill:#f59e0b,color:#000
    style K fill:#ef4444,color:#fff
    style L fill:#ec4899,color:#fff
```

| Metric | Value |
|---|---|
| Accuracy | ~90% |
| Model | TF-IDF + Logistic Regression, trained from a CSV dataset |
| Inputs | Text, images (OCR) and email scanning via Gmail API / IMAP |
| Output | Real / Suspicious / Fake label with confidence score and explanation, plus batch filtering |
| Config | Prediction thresholds adjustable in `src/config.py` |
